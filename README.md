I'm a PhD researcher at **Otto von Guericke University Magdeburg (OVGU)** working on robot perception and navigation — SAR-SLAM, scene graph generation, and human trajectory estimation for mobile robots. Alongside research, I run **Irama**, building operational and dashboard tooling.
